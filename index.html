30日チャレンジ

Claude Code を使って、毎日一つ「AI に実際に仕事をさせる」練習をしています。本を読んで学ぶのではなく、手を動かして、毎日なにか一つ、できあがったものを残すことにしています。

最終的には、AI を学んでいる人をサポートするスマホアプリを作りたいと考えています。AI を学んでいる人も、つい三日坊主になりがちです。毎日お題が出て、それを一つずつクリアしていく。そんなアプリを目指しています。

  • 第1週文章とファイルを扱う
  • 第2週データと自動化
  • 第3週
    自分のページを作って公開する
    （このページは、その15日目に作りました）
  • 第4週作ったものを、人に差し出す形にする
  • 今日のお題を見る
